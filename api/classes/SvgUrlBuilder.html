    Class SvgUrlBuilder

    Fluent builder class for constructing SVG URLs with method chaining

    Example

    const url = new SvgUrlBuilder('marker')
      .size(44, 44)
      .pixelRatio(2)
      .colors({ fg: '#d35400', bg: '#ffffff' })
      .text('EWR', { fontSize: 18, textColor: '#d35400' })
      .build();
